# E-Voting Local Card Agent

โปรแกรมตัวเล็กที่รันบน **เครื่องคูหา** (เครื่องที่เสียบเครื่องอ่านบัตรประชาชน USB จริง)
ทำหน้าที่อ่านบัตรผ่าน PC/SC แล้วส่งข้อมูลให้หน้าเว็บระบบเลือกตั้งผ่าน WebSocket บน `localhost`

## ทำไมต้องมี Agent

เว็บระบบเลือกตั้งโฮสต์อยู่บน Cloud (Coolify) เข้าถึงได้จากทุกเครื่อง แต่ **เบราว์เซอร์เข้าถึง
เครื่องอ่านบัตร USB โดยตรงไม่ได้** และเซิร์ฟเวอร์บน Cloud ก็อยู่คนละเครื่องกับเครื่องอ่านบัตร
Agent นี้จึงเป็น "สะพาน" ที่รันบนเครื่องคูหาเดียวกับเครื่องอ่านบัตร

```
Cloud (Coolify)  ← เปิดจากเครื่องไหนก็ได้
      ↑  เบราว์เซอร์ (ส่งข้อมูลบัตรไปตรวจสิทธิ์)
      |
เครื่องคูหา
  ├─ Card Agent (โปรแกรมนี้) รันอยู่
  ├─ เครื่องอ่านบัตร USB เสียบไว้     ✅ Agent อ่านบัตร
  └─ เบราว์เซอร์เปิดเว็บ → คุยกับ Agent ที่ ws://127.0.0.1:47458
```

## วิธีใช้งานที่แนะนำ — "One-Click" (ไม่ต้องติดตั้งอะไรบนเครื่องคูหา)

เครื่องคูหา **ไม่ต้องมี Node.js และไม่ต้องมีเครื่องมือคอมไพล์** ขอแค่มีชุดติดตั้ง
สำเร็จรูป (`agent-dist`) แล้วดับเบิลคลิกไฟล์เดียว

### ขั้นที่ 1 — ผู้ดูแลสร้างชุดติดตั้งสำเร็จรูป (ทำครั้งเดียว)

บนเครื่องนักพัฒนา/เครื่องที่มี **Node.js + Visual Studio Build Tools (C++) + Python**:

```
ดับเบิลคลิก  agent\package-agent.bat
```

สคริปต์จะ (1) คอมไพล์ไลบรารีอ่านบัตร (2) ดาวน์โหลด Node.js แบบพกพา (3) รวมทุกอย่าง
ไว้ในโฟลเดอร์ **`agent-dist`** (อยู่ระดับเดียวกับโฟลเดอร์ `agent`)

### ขั้นที่ 2 — นำไปใช้ที่เครื่องคูหา

1. คัดลอกโฟลเดอร์ **`agent-dist`** ทั้งโฟลเดอร์ไปยังเครื่องคูหา
2. เสียบเครื่องอ่านบัตร USB
3. **ดับเบิลคลิก `start-agent.bat`** — จบ! (ไม่ต้องต่อเน็ต ไม่ต้องติดตั้งอะไร)

เมื่อขึ้นข้อความ `พร้อมใช้งานที่ ws://127.0.0.1:47458` ให้เปิดหน้าเว็บระบบเลือกตั้ง
บนเครื่องเดียวกัน แล้วเสียบบัตรได้เลย — ไฟสถานะ "เครื่องอ่านบัตร" บนหน้าคูหาจะติดเขียว

> เปิด Agent ทิ้งไว้ตลอดการลงคะแนน ปิดด้วย `Ctrl+C` หรือปิดหน้าต่าง

## ทางเลือก — รันจากซอร์สโดยตรง

ถ้าเปิด `start-agent.bat` จากในโฟลเดอร์ `agent` (ที่ยังไม่ได้ package):

- ถ้าเครื่อง **ไม่มี Node.js** หรือรุ่นไม่ตรง (ต้อง ABI 127 = Node 22) ตัวสคริปต์จะ
  **ดาวน์โหลด Node.js แบบพกพาให้อัตโนมัติ** (ต้องต่ออินเทอร์เน็ตครั้งแรก ไม่ต้องเป็น Admin)
- ถ้ายังไม่เคย `npm install` และเครื่อง **ไม่มี Build Tools** การคอมไพล์ไลบรารีอ่านบัตร
  จะล้มเหลว → ให้ใช้วิธี One-Click (agent-dist) ด้านบนแทน

ความต้องการของเครื่องคูหา (Windows): มี **เครื่องอ่านบัตร Smart Card USB (CCID)** เสียบไว้
โดยทั่วไป Windows มีบริการ Smart Card (`SCardSvr`) + ไดรเวอร์ CCID มาให้อยู่แล้ว เสียบแล้วใช้ได้เลย

## การตั้งค่า (ไม่บังคับ)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `AGENT_PORT` | `47458` | พอร์ต WebSocket ของ Agent |
| `ALLOW_ORIGIN` | `*` | โดเมนหน้าเว็บที่อนุญาต (เช่น `https://vote.example.com`) |

ตัวอย่าง (PowerShell):

```powershell
$env:AGENT_PORT = "50000"; node card-agent.js
```

ถ้าเปลี่ยนพอร์ต ให้เปิดหน้าเว็บด้วย `?agent=50000` ต่อท้าย URL หนึ่งครั้ง
(ระบบจะจำไว้ใน localStorage)

## แก้ปัญหาที่พบบ่อย

- **ไฟเครื่องอ่านบัตรไม่ติดเขียว / หน้าเว็บไม่เชื่อม Agent**
  - ตรวจว่า Agent กำลังรันอยู่ (มีหน้าต่าง console เปิดค้าง)
  - เปิดหน้าเว็บบน **เครื่องเดียวกับ Agent** เท่านั้น (localhost)
  - ลองเปิด `http://127.0.0.1:47458` ในเบราว์เซอร์ ควรเห็น JSON `{"ok":true,...}`
- **`npm install` ล้มเหลว (คอมไพล์ไม่ผ่าน)** — ติดตั้ง Visual Studio Build Tools (C++) + Python
- **อ่านบัตรไม่ได้** — ตรวจว่าบริการ "Smart Card" ของ Windows เปิดอยู่ และลองเสียบบัตรให้แน่น

## ข้อควรทราบด้านความปลอดภัย

ในสถาปัตยกรรมนี้ข้อมูลบัตร (เลขบัตร + ชื่อ) เดินทางจาก Agent → เบราว์เซอร์ → เซิร์ฟเวอร์
จึงควรใช้ร่วมกับการ **มีเจ้าหน้าที่กำกับหน้าคูหา** ตามปกติของการเลือกตั้ง หากต้องการความ
เข้มงวดขึ้น (ให้ Agent ส่งข้อมูลตรงไปเซิร์ฟเวอร์พร้อมลายเซ็นต่อสถานี) แจ้งผู้พัฒนาเพื่อ
เปิดโหมดนั้นเพิ่มได้
